Como Testar a Extensão:
  1. Pressione Alt + Shift + L ou clique no ícone da extensão para ativar o Target Cursor Tracker.
  2. Mova o cursor pela página. Observe os 4 cantos brancos orbitando suavemente e mudando para Rosa Orkut (#ED2590) ao passar sobre os elementos.
  3. Clique em qualquer elemento para abrir o Lobnho Inspector Modal.
  4. Navegue pelas abas: HTML, CSS, React JSX, Animações, Tipografia, Assets, Tailwind, Figma (SVG).
  5. Clique no botão Copiar Aba Ativa e cole em seu editor para validar a geração limpa do código.

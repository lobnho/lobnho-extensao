# Lobnho Extension

Extensão de navegador (Manifest V3) para inspeção de elementos e exportação de páginas completas.

## O que faz

- **Inspeção de Elementos**: Mira visual para selecionar qualquer elemento na página e gerar código na hora (HTML, CSS, React JSX, Tailwind CSS e SVG para Figma).
- **Salvar Página Completa**: Baixa a página inteira em um único arquivo `.html` offline com estilos, fontes e imagens embutidos, scripts neutralizados e dados vetoriais para Figma/Adobe.

## Como Instalar

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/lobnho/lobnho-extensao.git
   ```
2. Abra `chrome://extensions` no navegador (Chrome, Brave, Edge, Opera).
3. Ative o **Modo do desenvolvedor** no canto superior direito.
4. Clique em **Carregar sem compactação** e selecione a pasta do repositório.

## Como Usar

- Clique no ícone da extensão ou pressione `Alt + Shift + L`.
- Clique em **Inspecionar elemento** para ativar a mira e clicar no componente desejado.
- Clique em **Salvar Página Completa (.html)** para gerar o arquivo offline.
